# Roblox Game Builders for Kids: Landing Page

A fun, colourful and fully responsive landing page for the topic **From Playing to Creating: Kids Can Build Their Own Roblox Games**.

## Description

Kids love playing Roblox. This landing page shows parents how that love can grow into real creativity and coding skills. It includes an interactive block builder where children snap Move, Jump and Grab Coin blocks together and press Run to watch their hero obey.

## Features

* Sticky header with clickable navigation and a Free Demo button
* Hero section with floating blocks and an interactive coding playground
* Four step path from Play to Create to Build to Share
* Modern cards with hover effects and scroll reveal animations
* Programs, blog and Flutter course cards
* Bold call to action band and clean footer
* Fully responsive, a single HTML file with no dependencies

## How to Use

1. Create a new GitHub repository and upload `index.html` and `README.md`.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your landing page goes live at `https://your-username.github.io/your-repo-name/`.

## Customise

Change the colours in the `:root` block at the top of the style section, and edit any text directly in `index.html`.
